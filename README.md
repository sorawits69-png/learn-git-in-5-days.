## 🎯 สรุปผลการเรียนรู้ 5 วัน (5-Day Summary)
* **Day 1: Setup & Initialization** — ติดตั้ง Git และตั้งค่า `user.name` / `user.email`
* **Day 2: Basic Workflow** — วงจรการทำงาน 3 สเต็ป (`git status` ➔ `git add` ➔ `git commit`)
* **Day 3: Branching & Merge Conflicts** — การแตก Branch และทดลองแก้ปัญหา Merge Conflict
* **Day 4: Remote Syncing** — เชื่อมต่อ Local Repo เข้ากับ GitHub Cloud ด้วย `git push`
* **Day 5: Synthesis & Sharing** — จัดทำ Cheat Sheet, สไลด์นำเสนอ และจัดเรียงเอกสารส่งงาน

## 🛠️ คำสั่งหลักที่ใช้ในโปรเจกต์ (Key Commands)
```bash
# 1. การเซฟงานลงประวัติ (Save Checkpoint)
git add .
git commit -m "feat: update project documentation"
# 2. การสร้างและจัดการไทม์ไลน์ (Branching)
git checkout -b feature/login-page
# 3. การส่งงานขึ้น GitHub Cloud (Sync to Cloud)
git push -u origin main
